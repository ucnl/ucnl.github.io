## KEY FEATURES

* Miniature and lightweight transducer based on a single cylindrical piezoelectric element
* Maintenance-free monoblock design made using a patented technology
* Complete absence of corroding elements
* High-quality shielded cable with polyurethane insulation
* Mounting groove
* Built-in band-pass filter

The device contains a 4th-order active band-pass filter for reception and a second-order passive LC filter for transmission.
