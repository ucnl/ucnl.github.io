## KEY FEATURES

* **GNSS receiver protocol emulation**
* **Built-in GNSS module**

## DESCRIPTION

The navigation buoy signal receiver of the **[WAYU](WAYU_DataBrief_en.md)** system receives signals from the [WAYU GIB](WAYU_GIB_Specification_en.md) navigation buoys and determines the location of the underwater object on which the [WAYU Pinger](WAYU_Pinger_Specification_en.md) pinger is located. The receiver is a maintenance-free monoblock on a cable.

## TECHNICAL SPECIFICATIONS

| PARAMETER | VALUE |
| :--- | :--- |
| DIMENSIONS (Ø x h, w/o cable) | 90 x 330 mm |
| WEIGHT | 0.5 kg |
| CABLE LENGTH | 1 m |
| CABLE DIAMETER | 10 ± 0.5 mm |
| OPERATING TEMPERATURE RANGE | -10 .. 50 °C |
| MAXIMUM RADIO COMMUNICATION RANGE<sup>[1](#footnote1)</sup> | 300 m |
| RADIO COMMUNICATION | 433 MHz, receive only |
| CONNECTION | To a PC USB port, USB-B |
| CURRENT CONSUMPTION | 150 mA |
| INTERFACE | RS-422, 38400 baud |
| PROTOCOL | [NMEA0183 (GGA, RMC), UNV](/documentation/EN/RWLT/uNav_protocol_specification_en) |
| BUILT-IN GNSS module | GPS/GLONASS |
| HOUSING MATERIAL | Polyurethane |

________________
<a name="footnote1"><sup>1</sup></a> Achieved in the absence of interference, in open areas.
