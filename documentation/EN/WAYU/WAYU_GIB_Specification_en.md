## KEY FEATURES

* **Minimum dimensions and weight**
* **Strong and durable maintenance-free housing**
* **Automatic activation in water**

## DESCRIPTION

The **WAYU GIB** navigation sonobuoy of the **[WAYU](WAYU_DataBrief_en.md)** system, in a set of four such devices, forms a floating long navigation base that supports positioning of the **[WAYU Pinger](WAYU_Pinger_Specification_en.md)** pinger.  
The device has a one-piece design, is made of high-strength polyurethane and polypropylene, and switches off automatically when it enters the water. It does not require any settings or calibrations. Buoyancy is provided by an easily noticeable float made of ethylene-vinyl acetate (EVA).

| BUILT-IN BATTERY CAPACITY | 18 W·h |
| TRANSDUCER CABLE LENGTH | 1 m |
| BUILT-IN RADIO MODULE TYPE | 433 MHz |
| MAXIMUM RADIO MODULE POWER | 100 mW |
| MAXIMUM RADIO COMMUNICATION RANGE<sup>[4](#footnote4)</sup> | 300 m |
| CHARGING THE BUILT-IN BATTERY | With the included charger |
| CHARGING TIME OF THE BUILT-IN BATTERY | 8 h |
