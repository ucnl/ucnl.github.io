## FEATURES

* Easy to use
* Small size and weight
* Up to 2 months on one charge<sup>[1](#footnote1)</sup>
* Automatic surfacing when the battery charge is low
* Maintenance-free potted housing

## DESCRIPTION

A simple and miniature solution for retrieving various types of seabed equipment installed for a long period (up to two months).
The device consists of an actuator with a built-in LiFePO4 battery and a reel that stores the anchor line in a coiled state.
Upon receiving a command from the control device or detecting a low battery charge, a screw actuator is activated, ensuring reliable release from the anchor and surfacing of the release unit itself with the float. After surfacing, the release unit remains connected to the anchor by the anchor line.
The [F4105-AU](F4105_AU_Specification_en.md) acoustic wake-up unit is used as the control device.

| Pin No. | I/O | Function |
| :--- | :--- | :--- |
| 1 | O | Power supply for the control device +5.2 .. +7.3 V |
| 2 | - | NC |
| 3 | I | CHARGE (Charging) +7.5 V, max. 1 A |
| 4 | I | ACT (Actuator activation signal) logic "1" LVTTL and TTL |
| 5 | - | Common |
