## FEATURES

* 64 unique addresses for acoustic releases
* Programming release addresses and issuing commands in one device
* Strong, durable plastic housing, IP67<sup>[1](#footnote1)</sup>
* Stainless steel panel
* Built-in LiFePO4 battery
* Operation at subzero temperatures

## DESCRIPTION

The device is designed to:
- assign addresses to [F4105-AU](F4105_AU_Specification_en.md) acoustic releases
- send an ascent command to acoustic releases controlled by [F4105-AU](F4105_AU_Specification_en.md)

The device has an IP67<sup>[1](#footnote1)</sup> protection class and can operate autonomously thanks to its built-in power supply.
