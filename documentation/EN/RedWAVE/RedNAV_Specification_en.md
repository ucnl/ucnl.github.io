## KEY FEATURES

* **Completely acoustically passive device**
* **3D position in absolute geographical coordinates**
* **Update rate of 3D position up to 1 Hz**
* **Minimum dimensions and weight**
* **Simultaneous operation of an unlimited number of devices<sup>[*](#footnote_a1)</sup>**
* **Reliable and noise-resistant digital broadband underwater acoustic communication technology**
* **Automatic track recording with export to KML and CSV formats**
* **Ability to preload waypoints and save points of interest**

## DESCRIPTION

**[RedWave](RedWAVE_DataBrief_en.md)** is the only system to date, created using patented<sup>[*](#footnote_a1)</sup> technology, that implements the so-called "underwater GPS": following exactly the ideology of GPS and other satellite systems, it allows an unlimited number of underwater objects to determine their geographical position at the same time.  

**RedNav** is the diver's navigation receiver of the **[RedWave](RedWAVE_DataBrief_en.md)** system, which allows a diver to determine their own geographical position while submerged, without the need to surface and use remote GPS antennas on a cable.  

With the support of four floating navigation sonobuoys [RedBase](RedBASE_Specification_en.md), simultaneous operation of an unlimited number of **RedNav** and [RedNode](RedNODE_Specification_en.md) devices is possible in one operating area.  

Working with the **RedNav** navigation receiver is in many ways similar to working with conventional GPS/GLONASS trackers and navigators, with the difference that the role of the satellites is performed by four small-sized relay sonobuoys [RedBase](RedBASE_Specification_en.md). The device itself is attached to the diver's wrist, and the transducer to the shoulder or tank.

The unique functionality and ease of use make RedNav an ideal solution for recreational diving as well as for search, archaeological and underwater engineering work.

## TECHNICAL SPECIFICATIONS

| PARAMETER | VALUE |
| :--- | :--- |
| DIMENSIONS (REMOTE UNIT, Ø x h) | 64 x 64 mm |
| DIMENSIONS (INTERFACE UNIT) | 84 x 118 x 36 mm |
| WEIGHT (dry) | 0.65 kg |
| MAXIMUM BATTERY LIFE | 8 hours |
| MAXIMUM VELOCITY RELATIVE TO BUOYS | +/- 1.8 m/s  |
| OPERATING TEMPERATURE RANGE | -5 .. 50 °C |
| MAXIMUM IMMERSION DEPTH | 70 m |
| MAXIMUM WORKING AREA SIZE | 700 x 700 m inside the buoy figure |
| MAXIMUM ACOUSTIC COMMUNICATION RANGE<sup>[1](#footnote1)</sup> | 3000 m |
| CARRIER FREQUENCY | 20100 Hz |
| MINIMUM SIGNAL-TO-NOISE RATIO (IN BAND)<sup>[2](#footnote2)</sup> | -6 dB |
| REFERENCE ELLIPSOID | WGS-84 |
| NOMINAL HORIZONTAL ACCURACY<sup>[3](#footnote3)</sup> (2DRMS) | 0.84 m |
| NOMINAL DEPTH ACCURACY<sup>[4](#footnote4)</sup>  | 0.1 m |
| NOMINAL TIME TO FIRST FIX | 28 s |
| NOMINAL POSITION UPDATE RATE | 1 Hz |
| NOMINAL STARTUP TIME | 3 s |
| BUILT-IN TEMPERATURE SENSOR ACCURACY | 0.1 °C |
| SYNCHRONIZATION WITH PC | Via the supplied USB dongle |
| CHARGING | Via the supplied USB dongle |
| BUILT-IN BATTERY TYPE | Lithium-ion |
| CABLE LENGTH | 1.2 m |
| ROUTE FUNCTIONS | Up to 20 uploadable points + <br/> up to 20 points saved during operation |
| TRACK RECORDING WITH THE ABILITY TO EXPORT TO KML AND CSV | Up to 2 hours<sup>[5](#footnote5)</sup> |
| ADDITIONAL FUNCTIONS | Depth, <br/> Water temperature |

________________
<a name="footnote1"><sup>1</sup></a> A parameter that determines the maximum range at which signal reception is possible, based on the electro-acoustic parameters of the transmitter and receiver, the spatial decrease in the intensity of sound energy, attenuation in the medium and the acoustic noise level.  
<a name="footnote2"><sup>2</sup></a> The value was obtained without taking the multipath propagation effect into account.  
<a name="footnote3"><sup>3</sup></a> The value was obtained by measurement in a real body of water with the buoys and the navigation receiver fixed in place for 60 minutes.  
<a name="footnote4"><sup>4</sup></a> The value may depend on the correctness of the salinity of the water in which the work is performed, as set by the user.  
<a name="footnote5"><sup>5</sup></a> During continuous operation of the device, taking into account the coordinate update rate of 1 Hz.
