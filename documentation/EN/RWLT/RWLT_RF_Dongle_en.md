## KEY FEATURES

* **IP68 protection class**
* **GNSS receiver protocol emulation**
* **Built-in GNSS module**

## DESCRIPTION

The navigation buoy signal receiver of the **[RWLT](RWLT_DataBrief_en.md)** system receives signals from the [RWLT GIB](RWLT_GIB_Specification_en.md) navigation buoys and determines the location of the underwater object on which the [RWLT Pinger](RWLT_Pinger_Specification_en.md) pinger is located. The receiver is a maintenance-free monoblock on a cable.

## TECHNICAL SPECIFICATIONS

| PARAMETER | VALUE |
| :--- | :--- |
| DIMENSIONS (Ø x h, w/o cable) | 90 x 330 mm |
| WEIGHT (w/ 10 m cable) | 1.4 kg |
| CABLE LENGTH | 10 m |
| CABLE DIAMETER | 10 ± 0.5 mm |
| OPERATING TEMPERATURE RANGE | -10 .. 50 °C |
| MAXIMUM RADIO COMMUNICATION RANGE<sup>[1](#footnote1)</sup> | 1000 m |
| RADIO COMMUNICATION | 433 MHz, receive only |
| CONNECTION | To a PC USB port via [Bat&Link Box](/documentation/EN/Zima/Bat_n_link_box_Specification_en) |
| INTERFACE | RS-422, 38400 baud |
| PROTOCOL | [NMEA0183 (GGA, RMC), UNV](/documentation/EN/RWLT/uNav_protocol_specification_en) |
| BUILT-IN GNSS module | GPS/GLONASS |
| HOUSING MATERIAL | Polyurethane |

________________
<a name="footnote1"><sup>1</sup></a> Achieved in the absence of interference, in open areas.
